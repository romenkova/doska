Attachments are currently supported only with the [self-hosting setup](/docs/self-hosting): they require a sync server.

Having attachments with the local setup is on the roadmap.

## How to attach files to a card?

### 1. Attachments button on the card

The paperclip in the card header opens the attachments panel.

![Paperclip button in the card header](/card-attachments-button.png)

Attached images can then be referenced via the slash menu:

![Attached file at the bottom of the slash menu](/card-slash-menu-attachment.png)

### 2. CMD+V with the attachment in the buffer

Focus the card's body, and paste an image.

### 3. Drag and drop the file to the card

## Deleting files

In edit mode on the card, click the `x` near the attachment to remove it.
