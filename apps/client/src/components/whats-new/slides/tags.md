# Tags

Tags got their own management. Open **Manage tags** in the board menu.

- **Rename** a tag and it changes on every card of the board. Rename onto an existing tag to merge them
- **Colors**: the board owner can give each tag a color, and it shows on cards and filter pills
- **Delete** takes the tag off every card. 
- Right-click any tag to filter by it or change its color
- The card menu's **Tags** list now has a search
